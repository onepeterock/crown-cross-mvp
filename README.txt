Crown & Cross Online Academy - Clickable MVP (Phase A)

How to view
1. Unzip this folder.
2. Open index.html in any browser (double-click it).
3. Choose a role and click through. Everything is navigable; forms and buttons are illustrative and do not save.

To put it on the web, upload the whole folder to any static host (Netlify drop, GitHub Pages, Vercel, cPanel) and share the address of index.html.

Fonts load from Google Fonts when online; offline the page falls back to system fonts.
